# HackClub Half Life My Starbie

This week I made the starter project, a starbie.

my Starbie is BMO from adventure time. during the second week I will create a housing for it that resembles him from the show. I chose BMO simply because he is cute and I thought it was a good fit as he is a robot.

<img width="32" height="32" alt="BMO_Sprite" src="https://github.com/user-attachments/assets/a99d92d2-bd47-49b4-a46a-8ec593bf37cd" />

My starbie is very simple, it is just the basic starbie but with a passive buzzer added so it can react with sounds. I simply use the passive buzzer which is in the Arduino Uno R3 super starter kit so that I could buy as little as possible. This entire project is very simple honestly, I didn't do anything special other than put things on the backside of the pcb which is not described in the week one tutorial, still very simple though.
